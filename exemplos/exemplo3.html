3.1 - EDOs de 2ª Ordem

Teste: marcações sobre camadas anteriores

Exemplo 3: Verifique que \(y=e^{ax}[\cos(bx)+\sen(bx)]\) é solução de \([(D-a)^2+b^2]y=0\).

Primeiro, para organizar os cálculos, seja \(v(x) = \cos (bx) + \sen(bx)\). Assim,

\(\displaystyle v'(x) = b[ - \sen(bx)+\cos (bx)]\) e \(\displaystyle v''(x) = b^2[-\cos(bx)-\sen(bx)] = \mk{m11}{-b^2v(x)}.\)

Além disso, \(\mk{m1}{y}=\mk{m12}{\ee^{ax}[v(x)]}\). Logo,

\(\displaystyle y'=a\mk{m2}{e^{ax}v} + e^{ax}v'\) \(\displaystyle {}= \mk{m4}{ay+ e^{ax}v'}.\)

Além disso,

\[ [(D-a)^2+b^2]y=0 \Imp (D-a)^2y=-b^2y. \]

Então, vamos desenvolver \((D-a)^2y\) e mostrar que é igual à \(\mk{m15}{-b^2y}\).

\(\displaystyle (D-a)^2[y] = (D-a)(D-a)[y] = (D-a)[Dy - ay] = (D-a)[\mk{m3}{y'-ay}]\)
\(\displaystyle \phantom{(D-a)^2[y]} = (D-a)[\mk{m5}{e^{ax}v'}]\)
\(\displaystyle \phantom{(D-a)^2[y]} = \mk{m6}{D[e^{ax}v']} - a[e^{ax}v']\), aplicando a Regra do Produto, temos
\(\displaystyle \phantom{(D-a)^2[y]} = a\ee^{ax}v'+\ee^{ax}v'' - ae^{ax}v'\), colocando \(\ee^{ax}\) em evidência,
\(\displaystyle \phantom{(D-a)^2[y]} = e^{ax}[\mk{m8}{av'}+\mk{m10}{v''} - \mk{m9}{av'}]\) \(\displaystyle {}= \mk{m13}{e^{ax}[-b^2v]}\)
\(\displaystyle \phantom{(D-a)^2[y]} = \mk{m16}{-b^2\mk{m14}{y}}\)◼
